# TASK-9: Правило target-size

Цель: проверять размер кликабельных целей по WCAG 2.2 AA. В axe это правило выключено по умолчанию.

## Сделать
1. Включить правило target-size при запуске axe (опция rules в вызове axe.run).
2. Добавить запись в словарь: простое название, кого касается, как исправить, роль design. Тексты по правилам TASK-2.
3. Добавить в tests/fixtures/basic.html маленькую кнопку (с aria-label, чтобы не сработало button-name), которая нарушает правило.

## Критерии приёмки
- Все проверки прошлых этапов проходят.
- Unit-тест: в запуске axe правило target-size включено, а список остальных опций не изменился.
- Unit-тест словаря покрывает новую запись (все поля, id существует в axe.getRules()).
- На обновлённом basic.html агент в Chromium видит target-size вместе с прежними четырьмя правилами.
